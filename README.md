# 📌 Backend - Gestion de Projets de Recherche  

Ce projet est un backend développé en **Spring Boot** permettant aux chercheurs de gérer leurs projets de recherche. Il propose une API REST pour **créer, mettre à jour et gérer les projets**, ainsi que leurs participants et entreprises associées.  

## 🏗️ Fonctionnalités principales  
✔️ Création et mise à jour de projets  
✔️ Gestion des participants et entreprises associées  
✔️ Authentification des utilisateurs et administrateurs  
✔️ Envoi automatique d'e-mails lors d'événements clés  
✔️ Documentation API avec Swagger  
✔️ Gestion des erreurs et logs  

---

## 🛠️ Technologies utilisées  
- **Langage** : Java 21  
- **Framework** : Spring Boot  
- **ORM** : Hibernate & JPA  
- **Base de données** : SQL (MySQL, PostgreSQL…)  
- **Outils** : Gradle, Lombok, Swagger, Docker  
- **Gestion des erreurs** : Spring Exception Handling
